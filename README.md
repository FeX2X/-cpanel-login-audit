## 👾 About The Project

**CPANEL LOGIN AUDIT** is a Python-based cybersecurity research project designed to analyze authentication responses and connection behavior in authorized cPanel test environments.

Built with Python and concurrent processing, this project demonstrates HTTP session handling, HTTPS communication, response analysis, and terminal-based reporting.

## ⚡ Features

- 🚀 Multithreaded request handling
- 🔐 Authentication response analysis
- 🌐 HTTPS endpoint support
- 📡 Connection error detection
- 🛡️ SSL error handling
- ⏱️ Configurable request timeout
- 📊 Real-time statistics
- 🎨 Colored terminal output
- 📁 Result reporting

## 🧰 Technologies

```bash

cd cpanel-login-audit
```

## ⚙️ Configuration

```python
INPUT_FILE = "cpanels.txt"
OUTPUT_VALID = "cpanel_valid.txt"

THREADS = 200
TIMEOUT = 15
```

```bash
python3 cpanel-login-audit.py
```
